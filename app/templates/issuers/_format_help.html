Composer un format

Du texte fixe (lettres sans accent, chiffres, - _ . /) et des balises entre accolades :

{% for key, label in help.items() %}
{{ key }}
{{ label }}
{% endfor %}

Le compteur repart à 1 chaque mois si le format contient l'année et le mois, chaque année s'il contient l'année, jamais sinon. Exemples : FA-{AAAA}-{NNNN} → FA-2026-0001 · F{AA}{MM}-{NNN} → F2611-001 · FACT-{NNNNNN} → FACT-000001 · {AAAA}-{L} → 2026-A.
